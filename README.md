# Sistema de Gerenciamento de Estoque

Arquivos iniciais do meu projeto em Python.

Este projeto tem como objetivo desenvolver um sistema de gerenciamento de estoque com operações CRUD (Create, Read, Update e Delete), realizando inicialmente o armazenamento dos dados em arquivos `.csv`.

Como evolução do projeto, a proposta é migrar essa estrutura para um banco de dados relacional com MySQL, transformando a persistência em CSV em uma solução baseada em banco de dados.

## Roadmap inicial do projeto(Possíveis alterações futuras)
- [ ] CRUD de produtos em Python
- [ ] Registro e controle de vendas
- [ ] Persistência em arquivos CSV
- [ ] Relatórios básicos de estoque e vendas
- [ ] Migração dos dados para MySQL
- [ ] Integração do sistema com MySQL
